# Lemex slash commands

Type `/` in the composer to see commands available in your session. Common commands include:

| Command        | Purpose                                     |
| -------------- | ------------------------------------------- |
| `/model`       | Choose a model and its settings.            |
| `/permissions` | Configure permissions and approvals.        |
| `/status`      | Show session settings and token usage.      |
| `/new`         | Start a new chat.                           |
| `/resume`      | Resume a saved chat.                        |
| `/fork`        | Fork the current chat.                      |
| `/review`      | Review current changes.                     |
| `/diff`        | Show the working-tree diff.                 |
| `/compact`     | Summarize the conversation to free context. |
| `/mcp`         | Inspect MCP tools and connections.          |
| `/memories`    | Configure local memories.                   |
| `/theme`       | Choose a theme.                             |
| `/keymap`      | Configure keyboard shortcuts.               |
| `/quit`        | Exit Lemex.                                 |

Some commands depend on enabled features or the connected server. Use `lemex setup` in your terminal to configure API credentials.
